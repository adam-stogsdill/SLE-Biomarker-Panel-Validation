# SLE-Biomarker-Panel-Validation
This repository contains the data and scripts for the analysis included in Adam Stogsdill's BMI 5330 Final Project. "Validation of Zhao et al. (2023) 5-gene SLE Biomarker Panel"

## Data
Data collected and created for this project is included in the `data` directory.

## Analysis Script
The 'real_analysis.ipynb' file contains all the primary analysis and data processing for this project.

## Network Visualization
The 'network_visualization.ipynb' file contains the code for visualizing the network of genes in the 5-gene panel and the second-degree network of genes.
